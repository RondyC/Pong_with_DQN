DQN Pong Agent (Fully-Connected + One-Channel)



Описание проекта

Реализация Deep Q-Network (DQN) агента для среды Atari Pong, использующего:

Только полносвязанные слои (FC) без свёрточных сетей

Одноканальное (черно-белое) представление кадров через разность соседних состояний

Dueling DQN архитектуру для разделения оценки ценности состояния и преимущества действий

Double DQN для уменьшения переоценки Q-функции

Prioritized Experience Replay (PER) для приоритетного выбора важных переходов

Градиентный клиппинг для стабилизации обучения

Фокус проекта — показать, как даже с ограниченной FC-архитектурой можно добавить современные улучшения и добиться стабильного процесса обучения.

Установка и зависимости

Клонировать репозиторий:

git clone https://github.com/yourusername/dqn-pong-fc-one-channel.git
cd dqn-pong-fc-one-channel

Создать и активировать виртуальное окружение (рекомендуется):

python3 -m venv venv
source venv/bin/activate

Установить зависимости:

pip install -r requirements.txt

Установить Atari среды:

pip install "gymnasium[atari]" autorom[accept-rom-license]
auto-rom --accept-license

Запуск обучения

python dqn_pong.py

Основные гиперпараметры задаются в начале скрипта:

n_episodes — число эпизодов обучения

batch_size — размер батча для replay

gamma — коэффициент дисконтирования

epsilon_start, epsilon_min, eps_decay — параметры ε-жадной стратегии

target_update — частота обновления целевой сети

lr — скорость обучения

n_frames — длина стека разностных кадров

PER: memory_size, alpha, beta_start и beta_inc

Результаты

Впервые агент показывает суммарное вознаграждение –21…–16 за эпизод в первые 100 эпизодов

График assets/reward_plot.png демонстрирует медленную, но стабильную адаптацию стратегии

Выводы

Работающий код: все компоненты (разностные кадры, Dueling, Double DQN, PER, клиппинг) успешно интегрированы.

Ограничения: FC-архитектура без свёрток не позволяет выйти в положительный reward в Pong за ограниченное время обучения.

Потенциал: добавление свёрточных слоёв или расширение набора методов (Multi-step, NoisyNet, Rainbow) может значительно улучшить результаты.
